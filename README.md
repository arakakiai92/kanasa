# LINEスタンプ・絵文字メーカー v6

iPhone・iPad・Android端末向け、お子様でも直感的に作れるLINEスタンプ＆絵文字Webアプリ。

## 今回の改善（最初の範囲指定での位置・サイズ調整）
1. **切り出し枠を指で直接スライド・サイズ調整**:
   - 枠の内側をつまんで指を滑らせると、枠の**位置を自由に移動**できます。
   - 枠の四隅の丸いつまみ（ハンドル）を引っ張ると、LINE規定の比率を保ったまま**拡大・縮小**できます。
   - 枠の外側をドラッグすると、いつでも**新しく囲み直す**ことができます。
   - 枠の中央に「✥」マークを付け、お子様でも「ここをつかんで動かせる」ことが一目でわかるようにしました。
2. **直感的な操作フロー**:
   - 最初のシート画面でぴったり位置と大きさを合わせてから「次へ：編集する →」に進めるため、調整の手間が大幅に減りました。
3. **レイヤー＆フリーフォント機能**:
   - 背景色（透過・パステルカラー）
   - セリフ（商用フリーGoogle Fonts 4種・文字フチどり・おすすめ言葉ボタン）

## アップロード手順 (GitHub Pages)
1. ダウンロードしたZIPファイルを解凍します。
2. リポジトリの `index.html`, `style.css`, `script.js`, `README.md` を上書きコミット＆プッシュします。
3. 数十秒ほどでPagesが更新され、実機でお試しいただけます。
