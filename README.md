# LINEスタンプ・絵文字メーカー v10 (カラーカスタマイズ強化版)

## 今回の新機能
1. **文字レイヤーの色変更（パレット ＋ 自由カラーピッカー）**:
   - 定番10色（黒・白・赤・青・緑・黄・オレンジ・ピンク・紫・茶）をワンタップ選択可能
   - **「🎨 自由カラーピッカー」**を追加。スマホのネイティブ色選択画面から好きな色を無制限に選べます。
2. **イラストの縁（フチ）のカラー変更機能**:
   - デフォルトは公式推奨の「白（#ffffff）」のまま、チェックを入れると色パレットが展開
   - 定番色（白・黒・薄ピンク・黄・水色・赤・緑・紫）および「🎨 自由カラーピッカー」から好きなフチ色を指定可能
   - 太さスライダー（1〜20px）と連動し、リアルタイムプレビュー＆PNG書き出しに忠実に反映
