# LINEスタンプ・絵文字メーカー v13 (スマホファーストUI最適化版)

スマートフォン実機（モバイルSafari / Chrome）での片手操作・親指操作に特化したUI刷新バージョン。

## 今回のUI改善（スマホでの優先順位に基づく設計変更）
ユーザー課題：「レイヤーの重なりよりも位置調整や大きさ調整がすぐ近くにないとスクロールしないといけないので不便」

### 1. プレビュー直下に「タブ」と「クイック大きさ＆位置操作」を最優先配置
- **プレビュー画面の真下**に `[ 🎨 イラスト ]` `[ 💬 文字 ]` `[ 🖼 背景 ]` のタブを配置。
- そのすぐ下に**「大きさスライダー」と「十字キー（▲▼◀▶・◎）」を常駐配置**。
- タブをタップするだけで、スライダーと十字キーがそのレイヤー（絵 / 文字 / 背景）の操作に瞬時に切り替わります。
- **プレビューを見ながら親指で操作でき、スクロールの往復がゼロ**になりました！

### 2. レイヤーの重なり順（▲手前／▼奥）をドロワー化
- 頻繁には触らない重なり順の巨大なリストをプレビュー下から退避。
- タブ右端の `[ 🔃 順序 ]` ボタンを押した時だけスッと開くアコーディオン・ドロワー形式に変更しました。
- 画面を占有せず、必要な時だけ呼び出して並べ替えできます。

### 3. 背景レイヤー選択の直感化
- 「背景なし（透明）」「まる型」「角丸プレート」「ぜんぶ塗る」をビジュアルカード4択で直感選択。

### 4. 白ぬけ防止（高精度背景透過）を継承
- 輪郭線バリア＆色差サンプリングにより、キャラクターの白い服や肌が消える現象を防御。
