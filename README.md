# LINEスタンプ・絵文字メーカー v8

iPhone・iPad・Android端末向け、お子様でも簡単に作れるLINEスタンプ＆絵文字Webアプリ。

## 今回の新機能：３レイヤーの自由な入れ替え（重なり順変更）
各レイヤーの横にある **「▲ 手前」「▼ 奥」ボタン** を押すだけで、レイヤーの重なり順を自由に入れ替えることができます。

- **初期状態**:
  - `第3層 (一番手前)`: 💬 文字（セリフ）
  - `第2層 (中間)`: 🎨 イラスト
  - `第1層 (一番奥)`: 🖼 はいけい
- **入れ替えの活用例**:
  - **イラストを一番手前にする**: 文字をイラストの背後に配置して、キャラクターの頭の後ろから文字が飛び出すような演出
  - **背景を手前にする**: 背景色ブロックを前面に重ねるデザイン
- **画面表示と書き出し**:
  - リアルタイムプレビュー画面・完成PNG書き出しのどちらも、入れ替えた重なり順（一番奥から手前へ）で正確に合成されます。

## ３レイヤーそれぞれの仕様
1. **💬 文字（セリフ）レイヤー**:
   - **無選択（未入力）ならそのまま（文字描画なし）**
   - 入力した文字がそのままリアルタイムに反映
   - 商用フリーGoogle Fonts 5種選択式（モッチーポップ、丸ゴシック、デラゴシック、はちまるポップ、キウイ丸）
   - 白フチ / 黒フチ / なし、文字色、サイズ調整
   - プレビュー画面上を指で直接ドラッグして位置を移動可能
2. **🎨 イラストレイヤー**:
   - 切り出し枠から元画像の高解像度を保持して直接切り出し
   - 拡大・縮小・中央寄せ、プレビュー指ドラッグ
   - 背景透過ON/OFF、白フチ付加(1〜20px)
3. **🖼 はいけいレイヤー**:
   - **無選択なら「とうめい (標準)」**で透過スタンプとして保存
   - 白やパステルカラーをワンタップで配置可能

## 切り出し画面（ステップ①）の直感操作
- **枠の中央（✥）をつかんでスライド** ➡ 枠の位置を自由に移動
- **四隅のハンドル（丸いつまみ）を引っ張る** ➡ 縦横比を固定したまま拡大・縮小
- **枠の外側をドラッグ** ➡ 新しい枠で囲み直し
- **↺ 枠をリセット** ➡ ワンタップで枠を消してやり直し可能
