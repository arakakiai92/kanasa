# LINEスタンプ・絵文字メーカー v11 (全レイヤー拡大縮小・位置調整＆並べ替え対応版)

スマートフォン実機でお子様でも直感的に使えるLINEスタンプ切り出し＆３レイヤー編集Webアプリ。

## 今回の機能追加・強化内容
1. **３レイヤー（文字・イラスト・背景）すべての拡大縮小・位置調整に対応**:
   - **💬 文字レイヤー**:
     - サイズスライダー（16〜76px）
     - 十字キー微調整、ワンタップ上下中央配置（⬆上 / ↕中央 / ⬇下）
     - プレビュー画面の直接ドラッグ＆2本指ピンチズーム
     - 商用フリーGoogle Fonts 5種、文字色（10色＋🎨カラーピッカー）、フチ（白/黒/なし）
   - **🎨 イラストレイヤー**:
     - 拡大縮小スライダー（40%〜300%）、十字キー微調整
     - プレビュードラッグ＆2本指ピンチズーム
     - 画面フィット（横幅に合わせる / 縦幅に合わせる）
     - 背景透過、フチ（色選択・太さ1〜20px）
   - **🖼 はいけいレイヤー**:
     - 形状選択（⬜全画面ベタ塗り / 🔲角丸プレート / ⚪まる型座布団）
     - 大きさスライダー（20%〜250%）、十字キー微調整
     - プレビュードラッグ＆2本指ピンチズーム
     - カラーパレット＋🎨自由カラーピッカー
     - 「キャラクターの背後にだけ丸いパステル背景を置く」などの高度なスタンプ演出が簡単に可能！
2. **レイヤーの並べ替え（重なり順変更）**:
   - 各レイヤーの「▲ 手前」「▼ 奥」ボタンで自由に重なり順を変更可能
   - 一番奥から一番手前まで忠実に合成描画・PNG書き出し
3. **操作性の統一と画面インジケーター**:
   - プレビュー左上に「💬 文字レイヤー編集中」などのタグを表示し、今どのレイヤーを指で動かしているかを一目で確認可能
