# LINEスタンプ・絵文字メーカー v4

iPhone・iPad・Android端末向け、お子様でも簡単に切り出し編集ができるWebアプリ。

## 主な機能 & 改善点
- **①切り出し画面の改善**:
  - 指で画面をなぞるといつでもスムーズに枠が作成・更新可能
  - 枠の指定をやり直せる**「↺ 枠をリセット」ボタン**を追加
  - 初めてでもわかりやすい「✂️ この絵を囲む」ガイドボタン
- **解像度劣化の防止**:
  - 画面表示用の縮小画像ではなく、アップロードされた元画像の高解像度データから直接切り出すため、書き出し画像がぼやけず鮮明
- **白縁追加の超高速化（フリーズ解消）**:
  - Canvas 2Dハードウェアアクセラレーションを活用し、スマホでも一瞬でプレビュー反映
  - 太さは1〜20pxで自由に調整可能
- **操作性の向上**:
  - 四隅の操作ハンドルを大きくし、スマホの指タッチでつかみやすく調整
  - 調整画面で画像を拡大した際の端切れバグを解消
- **LINE公式規定対応**:
  - スタンプ：370 × 320 px (比率 370:320)
  - 絵文字：180 × 180 px (比率 1:1)
  - PNG書き出し、1MB超過チェック付き
- **スマホ保存サポート**:
  - 完成サムネイルをタップすると拡大表示され、iOS Safari / Androidで長押しから「写真に追加」可能
  - パソコンや対応端末向けのZIP一括保存も搭載

## 使い方 (GitHub Pages)
1. GitHubのリポジトリに `index.html`, `style.css`, `script.js` をコミット＆プッシュします。
2. Settings → Pages → Build and deployment で `Deploy from a branch` (main / root) を選択。
3. 発行されたURLをお子様のスマホやタブレットで開きます。
