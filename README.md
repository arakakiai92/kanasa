# LINEスタンプ・絵文字メーカー v3

iPhone SE2 / Androidタブレット向け試作版。

## 主な機能
- スタンプ：370:320の固定比率
- 絵文字：1:1の固定比率
- シート上で指でざっくり範囲指定
- 2段階目の調整画面
- 背景透過
- **透過後に白縁を追加**
- 白縁は1〜20pxで調整可能
- 透過結果をチェッカー背景でプレビュー
- スタンプは370×320、絵文字は180×180でPNG書き出し
- 1MB超過の簡易チェック
- 個別PNG保存、ZIP一括保存

## 白縁について
「⭕ 白縁をつける」をONにすると、透過されたイラストの外周アルファ形状を膨張させ、その外側に白い縁を作ります。
イラスト内部の白色そのものを基準にしていないため、白い顔・目・服などを一律に白く塗る方式ではありません。

## GitHub Pages
1. Public repositoryを作成
2. `index.html`, `style.css`, `script.js` をアップロード
3. Settings → Pages → Deploy from a branch → main / root
4. 発行URLをiPhone Safariで開く

※ ZIP生成のためJSZipをCDNから読み込みます。
※ 背景透過は「外周とつながった白〜薄色背景」を消す方式です。複雑な背景では完全除去できない場合があります。
※ LINEの最新審査規定が変更された場合は、最新の公式ガイドラインを優先してください。
