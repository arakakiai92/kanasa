# LINEスタンプ・絵文字メーカー v5

iPhone・iPad・Android端末向け、お子様でも簡単に作れるLINEスタンプ＆絵文字Webアプリ。

## 今回の新機能（レイヤー機能＆フリーフォント）
1. **💬 セリフ（文字）レイヤー**:
   - Google Fontsの商用フリーフォント4種類を内蔵（モッチーポップ、丸ゴシック、デラゴシック、手書き風）
   - 文字がイラストに埋もれない「白フチ・黒フチ」の縁取り機能
   - 文字の位置（上・中・下）やサイズの変更
   - 低学年のお子様でもワンタップで入力できる「おすすめ言葉ボタン」（ありがとう、OK、りょうかい等）
2. **🖼 はいけいレイヤー**:
   - 透過（透明）のほか、白やパステルカラー（ピンク、きいろ、みずいろ等）をワンタップ指定可能
3. **🎨 レイヤー切り替えタブ**:
   - 「えの調整」「はいけい」「セリフ」をタブでスムーズに切り替え
4. **↺ 枠のリセットボタン**:
   - 切り出し枠をワンタップで消去して囲み直す機能

## アップロード・更新手順 (GitHub Pages)
1. ダウンロードしたZIPを解凍します。
2. GitHubのリポジトリに `index.html`, `style.css`, `script.js`, `README.md` を上書きコミット＆プッシュします。
3. 数十秒ほどでPagesが自動更新され、スマートフォンのブラウザで最新機能がご利用いただけます。
