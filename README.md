# LINEスタンプ・絵文字メーカー（単体イラスト対応版）

現在の最新版コードに、単体イラストから直接レイヤー編集へ入る機能を追加した版です。

## 追加機能
- 「📋 AIシートから作る」：従来どおり、シート上で範囲を選択してからレイヤー編集へ
- 「🎨 1枚のイラストから作る」：切り出し画面をスキップして、直接レイヤー編集へ
- 単体イラストでもスタンプ／絵文字のモードに応じたキャンバス比率で編集
- 既存の消しゴム、背景透過、白ぬけ防止、フチ、文字、背景、レイヤー順、保存機能をそのまま利用
- 自動保存にも画像の読み込み方法（シート／単体）を保存
- 単体イラストで「戻る」を押した場合は切り出し画面を表示せず、画像選択エリアへ戻る

## 使い方
1. スタンプ／絵文字を選択
2. 「AIシートから作る」または「1枚のイラストから作る」を選択
3. 画像を選ぶ
4. 単体イラストなら自動的に「レイヤー編集」へ進む

GitHub Pagesでは `index.html`, `style.css`, `script.js` をリポジトリ直下に置いてください。


## v4 追加：AIシートの不要部分を直す修正ブラシ
レイヤー編集画面に「🖌️ 画像をちょっと修正」を追加しました。

- 「周囲の色で塗る」：周囲8方向の色をサンプリングして、柔らかいブラシで塗ります
- 「消しゴム」：透明にします
- ブラシサイズ：6〜80px
- ↩️ 戻す：修正を最大15回まで戻せます
- 指でなぞって操作可能
- 保存時は修正後の画像が使われます

使い方例：
AIが口の上に不要な舌などを描いた場合、周囲の肌色・口内色などを使って、その部分を指でなぞって修正します。
