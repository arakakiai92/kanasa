# LINEスタンプ・絵文字メーカー v12 (白ぬけ防止・高精度透過版)

スマートフォン実機でお子様でも直感的に使えるLINEスタンプ切り出し＆３レイヤー編集Webアプリ。

## 今回の不具合修正（白い部分が消える問題の解決）
キャラクターの白い服・肌・白目が透過によって消えてしまう現象を根本改修しました。

1. **背景判定の厳密化（無差別な白色消去の撤廃）**:
   - 四隅の境界から真の背景色をサンプリングし、指定した色差（しきい値）の範囲内のみを背景として判定。
   - 以前のコードにあった「明るい色を無条件で背景とする」危険なロジックを完全撤廃しました。
2. **🛡️ 白ぬけ防止（輪郭線バリア）の実装**:
   - 線画や輪郭のエッジを自動検知し、微小な隙間を塞ぐ「進入禁止バリア」を構築。
   - 細い線画やアンチエイリアスの薄い隙間からキャラ内部の白い部分に色が抜けるのを徹底防御します。
3. **透過のつよさ（感度）スライダー ＆ 白ぬけ防止トグル**:
   - イラストレイヤーに「透過のつよさ（5〜60）」スライダーを新設（デフォルト：22）。
   - 万が一キャラの白い部分が消える場合は、スライダーを少し左（弱く）にするだけで簡単に調整できます。
4. **元画像ベースの透過キャッシュ機構**:
   - 切り出し元画像の段階で透過処理を行いキャッシュするため、キャラを画面端に移動・見切れさせても切断面から色が抜けることが一切なくなりました。
   - プレビューの移動・拡大縮小・ピンチズームもカクつかず爆速で動作します。

## 主な機能一覧
- **３レイヤー構成（文字・イラスト・背景）**:
  - 全レイヤーの拡大縮小・位置調整・プレビュードラッグ・2本指ピンチ操作対応
  - レイヤーの重なり順（▲手前 / ▼奥）並び替え
- **文字レイヤー**:
  - 商用フリーGoogle Fonts 5種
  - 文字色（10色＋🎨自由カラーピッカー）
  - フチどり（白/黒/なし）
  - ワンタップ位置合わせ（上/中央/下）
- **イラストレイヤー**:
  - 高画質切り抜き、白ぬけ防止背景透過、フチ（色選択・太さ1〜20px）
- **背景レイヤー**:
  - 形状選択（全画面 / 角丸プレート / 丸型座布団）
  - パレット＋🎨自由カラーピッカー
